# Sales Data Engineering Pipeline

## Project Overview
This project demonstrates basic data engineering concepts
using sales data.

## Tools Used
- Git
- GitHub
- Linux
- Python
- SQL

## Pipeline Steps
1. Extract sales data
2. Clean and validate data
3. Transform data
4. Store processed data
5. Generate a report

## Learning Goals
- Version control with Git
- Branching and merging
- Pull requests using GitHub
- Building data pipelines# sales-data-pipelines
A beginner data engineering project using python and sql
